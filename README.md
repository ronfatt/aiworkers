# OmniFlow AI Social Studio (AI 社媒多智能体实时工作室)

OmniFlow 是一个专为 **社交媒体代运营 / 内容矩阵运营** 打造的 **可视化多智能体虚拟办公室与内容审核系统**。

将复杂的全网热点嗅探、15 秒黄金分镜脚本拆解、专属模型生成（Google Flow、可灵 Kling、Higgsfield Seedance 2.5、Suno、GPT Image）以及社媒数据复盘，直观映射为一个高科技感的 **2D 虚拟协作办公室**。

---

## 🌟 核心功能特性

### 1. 2D 实时多智能体虚拟办公室 (Virtual Studio)
* **策划与情报工位 (Desk Zone)**：
  * `Trend_Scout`：全网热点嗅探（TikTok 爆款音效与上升趋势）
  * `RedBook_Radar`：小红书爆款封面与互动率雷达
  * `Script_Master`：15 秒黄金三段式脚本架构（0~3s Hook / 3~10s 演示 / 10~15s CTA）
  * `Copy_Alchemist`：多平台双语文案与本地化 Hashtag 排版
* **视听生产基地 (Production Studio - 专属工具链)**：
  * `Google_Flow_Op`：主力 15s 视频流与全局镜头控速
  * `Kling_Aesthetic`：可灵 AI 1.5 专攻高美感光影与面部情绪特写
  * `Seedance_Motion`：Higgsfield Seedance 2.5 专攻物理级运镜（夹粉拉丝、产品按压）
  * `Suno_Music_Op`：Suno v3.5 专攻 15s 探店卡点神曲（3.0s 精准 Beat Drop）与 Google Flow Music 氛围垫音
  * `GPT_Image_Master`：GPT Image 直出 40% 份额的小红书 3:4 爆款大字封面与干货卡片
  * `Higgsfield_Vision`：微观质感与艺术特效增强
* **策略圆桌会议室 (Meeting Zone)**：
  * 专属主理人席位（👑 你 / Studio Director）
  * 一键点击 **【📢 召集 AI 专项圆桌会】**：全员实时起立迈步走入会议室，进行剧本式视听分工汇报
  * 平时每隔数秒自主跨区串门讨论（支持实时平滑走动与漫画式气泡弹窗）
* **休闲与客户管线区 (Lounge & Pipeline)**：
  * 实时跟踪当前客户（如：Tomato Boy 番茄仔海鲜粉）进度

### 2. 人工把关审核台 (Human-in-the-Loop Deck)
* **60% 15秒短视频真实交互模拟器**：
  * 9:16 手机竖屏预览
  * 0~3s / 3~10s / 10~15s 动态进度条联动与实时字幕切换
  * 顶部交互式切换 **`🎵 Suno 卡点`** 与 **`🎼 Flow 氛围音`**
  * 各分镜独立重调控制（调 Kling、调 Seedance、调 Suno、调 Google Flow）
* **40% 小红书/IG 轮播图模拟器**：
  * 支持多页 Carousel 快速切换与排版检验
* **一键排期发布 (Approve & Schedule)**

### 3. 数据归因与次日策略自动反哺 (Insight Oracle)
* 昨日 15s 视频完播衰减曲线分析
* 自动提炼《明日 Post 策略微调指令》并一键注入提示词

## 🛠 技术栈

* **前端框架**：React 18 + Vite
* **样式与视觉**：Tailwind CSS + Lucide React + 原生 SVG 动态连线与光流动效
* **动效引擎**：CSS Keyframe Walking/Bouncing + Pop-in Bubbles

## 🚀 本地启动指引

1. 克隆代码库：
```bash
git clone https://github.com/ronfatt/aiworkers.git
cd aiworkers
```

2. 安装依赖：
```bash
npm install
```

3. 启动开发服务器：
```bash
npm run dev
```

4. 打开浏览器访问：
```text
http://localhost:5173/
```
